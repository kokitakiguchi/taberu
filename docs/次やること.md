## 既存タスク（変わらず優先）

### 1. Claude APIキーをセットして分析を動かす ← 最優先

`.env` ファイルに以下を書いてバックエンドを再起動する：

```
CLAUDE_API_KEY=sk-ant-xxxxxxxx
```

確認方法：写真をアップロードして、カロリーや食材名が自動で入力されたら成功。

---

### 2. 分析が失敗したときの動作を確認する

AI分析に失敗したとき「手動で入力してください」という画面が出るか確認する。
（APIキーなしで試せば再現できる）

---

### 3. 統計グラフを確認する

Analytics ページ（`/analytics`）を開いて、グラフが実際のデータで描画されるかみる。
グラフが出ない場合はバックエンドの `/api/stats/calories` を確認。

---

### 4. 大きい画像を送ってみる

5MB を超える写真を送ったとき、自動でリサイズされてエラーにならないか確認する。
（iPhoneの写真などは大きいことが多い）
